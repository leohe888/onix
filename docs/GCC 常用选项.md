# GCC 常用选项

- `-E`：预处理。默认输出到标准输出。可以通过重定向或者 `-o` 选项输出到文件。
- `-S`：编译。默认输出到与源文件同名的 `.s` 文件中。可以通过 `-o` 选项指定输出文件名。
- `-c`：汇编。默认输出到与源文件同名的 `.o` 文件中。可以通过 `-o` 选项指定输出文件名。
- `-o`：指定输出文件名。
- `-I<directory>`：指定头文件搜索路径。`<directory>` 为目录路径，中间可加空格也可不加。
- `-L<directory>`：指定库文件搜索路径。`<directory>` 为目录路径，中间可加空格也可不加。
- `-l<library>`：指定要链接的库文件。中间不能加空格。GCC 会自动在 `<library>` 前加上 `lib` 前缀，并在其后加上 `.a` 或 `.so` 后缀。
- `-m32` / `-m64`：生成 32 位或 64 位代码。无该选项时，GCC 默认生成与自身架构一致的代码（64 位 GCC 默认为 -m64）。

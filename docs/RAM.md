# RAM

RAM（Random Access Memory，随机存取存储器）可分为：

- SRAM（Static Random Access Memory，静态随机存取存储器）：
  - 每个存储单元由 1 个电容 + 1 个晶体管组成，电容需定期刷新补充电荷，否则数据衰减丢失。
  - 速度快，功耗高，集成度低，成本高，容量小。
  - 常用作 Cache。
- DRAM（Dynamic Random Access Memory，动态随机存取存储器）：
  - 每个存储单元由 6 个晶体管组成，无需刷新，断电后仍会快速丢失数据。
  - 速度慢，功耗低，集成度高，成本低，容量大。
  - 常用作内存。

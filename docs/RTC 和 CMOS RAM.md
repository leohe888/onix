# RTC 和 CMOS RAM

RTC（Real-Time Clock，实时时钟）：负责记录当前时间。
CMOS RAM（Complementary Metal-Oxide-Semiconductor Random Access Memory，互补金属氧化物半导体随机存取存储器）：负责存储时间以及其他配置信息。它是基于 CMOS 工艺的静态随机存取存储器（Satic Random Access Memory，SRAM）。

RTC 和 CMOS RAM 通常集成在同一芯片上，摩托罗拉 MC146818A 是一个典型的 RTC 和 CMOS RAM 芯片。它们是由电池供电的，因此即使系统断电，它们也能继续工作。

RTC 由一个振荡频率为 32.768kHz 的石英晶体振荡器（晶振）驱动，经分频后，用于对 CMOS RAM 进行每秒一次的时间刷新。

CMOS RAM 的大小通常为 64 字节（也有更大的），其访问需要通过以下 I/O 端口进行：

- `0x70`：索引端口，用来指定 CMOS RAM 内存单元的偏移地址。大小为 8 位。其中，位 7 是 NMI（Non-Maskable Interrupt，不可屏蔽中断）的开关。
- `0x71`：数据端口，用来读写相应单元里的内容。大小为 8 位。

| 0x05        | 闹钟小时值                  |
| 0x06        | 一周中的当前天 (实时时钟)   |
| 0x07        | 一月中的当日日期 (实时时钟) |
| 0x08        | 当前月份 (实时时钟)         |
| 0x09        | 当前年份 (实时时钟)         |
| 0x0a        | RTC 状态寄存器 A            |
| 0x0b        | RTC 状态寄存器 B            |
| 0x0c        | RTC 状态寄存器 C            |
| 0x0d        | RTC 状态寄存器 D            |
| 0x0e        | POST 诊断状态字节           |
| 0x0f        | 停机状态字节                |
| 0x10        | 磁盘驱动器类型              |
| 0x11        | 保留                        |
| 0x12        | 硬盘驱动器类型              |
| 0x13        | 保留                        |
| 0x14        | 设备字节                    |
| 0x15        | 基本内存 (低字节)           |
| 0x16        | 基本内存 (高字节)           |
| 0x17        | 扩展内存 (低字节)           |
| 0x18        | 扩展内存 (高字节)           |
| 0x19 ~ 0x2d | 保留                        |
| 0x2e        | 校验和 (低字节)             |
| 0x2f        | 校验和 (高字节)             |
| 0x30        | 1Mb 以上的扩展内存 (低字节) |
| 0x31        | 1Mb 以上的扩展内存 (高字节) |
| 0x32        | 当前所处世纪值              |
| 0x33        | 信息标志                    |

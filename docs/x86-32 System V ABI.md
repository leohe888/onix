# x86-32 System V ABI

## 寄存器使用规则

- 调用者保存（caller-saved）：
  - eax
  - ecx
  - edx
- 被调用者保存（callee-saved）：
  - ebx
  - esi
  - edi
  - ebp
  - esp

## 函数调用约定

- 栈帧布局：

    ```text
    +---------------------------+   <-- 高地址
    | ...                       |
    +---------------------------+
    | 参数 2                    |
    +---------------------------+
    | 参数 1                    |
    +---------------------------+
    | 返回地址                  |
    +===========================+   <-- ebp
    | 调用者的栈帧基址           |
    +---------------------------+
    | 局部变量 N                 |
    +---------------------------+
    | 局部变量 N - 1             |
    +---------------------------+
    | ...                       |
    +---------------------------+   <-- 低地址
    ```

- 栈帧切换：

    ```nasm
    func:
        ; 等价于 enter
        push ebp
        mov ebp, esp
        ...
        ; 等价于 leave
        mov esp, ebp
        pop ebp
        ret
    ```

- 返回值通常放在 eax 寄存器中。

## 系统调用约定

- 调用指令：`int 0x80`。
- 参数：
  - eax：存储系统调用号。
  - ebx：存储第一个参数。
  - ecx：存储第二个参数。
  - edx：存储第三个参数。
  - esi：存储第四个参数。
  - edi：存储第五个参数。
  - ebp：存储第六个参数。
- 返回值：
  - eax：存储返回值。

# 中断

## 中断的分类

- 外中断：CPU 外部触发。
  - 可屏蔽中断 —— INTR。
  - 不可屏蔽中断 —— NMI。
- 内中断：CPU 内部触发。
  - 软中断：`INT n`。
  - 异常：
    - 故障。
    - 陷阱。
    - 终止。

## 实模式中断

### 中断向量表

- 中断向量：中断服务程序（Interrupt Service Routine，ISR）的入口地址，大小为 4 字节。低 2 字节是 ISR 的偏移地址（IP），高 2 字节是 ISR 的段地址（CS）。
- 中断向量表（Interrupt Vector Table，IVT）：中断向量的集合，共 256 个中断向量（对应中断类型号 0~255），占用 1024 字节（1 KB）。IVT 固定存储在物理地址 0x0000~0x03FF 处。

## 保护模式中断

### 中断描述符表

- 中断描述符：描述中断服务程序的入口地址和访问属性，大小为 8 字节。

    ```c
    typedef struct gate_t
    {
        u16 offset0;    // 段内偏移 0 ~ 15 位
        u16 selector;   // 代码段选择子
        u8 reserved;    // 保留不用
        u8 type : 4;    // 任务门/中断门/陷阱门
        u8 segment : 1; // segment = 0 表示系统段
        u8 DPL : 2;     // 使用 int 指令访问的最低权限
        u8 present : 1; // 是否有效
        u16 offset1;    // 段内偏移 16 ~ 31 位
    } _packed gate_t;
    ```

  - type（segment = 0）：
    - 0b0101：任务门（Task Gate）。
    - 0b1110：中断门（Interrupt Gate）。
    - 0b1111：陷阱门（Trap Gate）。

- 中断描述符表（Interrupt Descriptor Table，IDT）：最多256个中断描述符（对应中断向量0~255）。IDT 的位置和大小由 IDTR 寄存器指定。

    ```c
    gate_t idt[IDT_SIZE];
    ```

    ```c
    typedef struct pointer
    {
        unsigned short limit; // size - 1
        unsigned int base;
    } __attribute__((packed)) pointer;
    ```

    ```nasm
    lidt [idt_ptr]; 加载 idt
    sidt [idt_ptr]; 保存 idt
    ```

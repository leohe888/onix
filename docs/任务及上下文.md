# 任务及上下文

任务是一个独立的执行流程，例如进程、线程、协程等，它拥有自己的上下文，大小为 4 KB，其结构如下：

```text
+---------------------------+   <-- 高地址 —— 栈底
| ...                       |
+---------------------------+
| eip                       |
+---------------------------+
| ebp                       |
+---------------------------+
| ebx                       |
+---------------------------+
| esi                       |
+---------------------------+
| edi                       |
+---------------------------+   <-- 栈顶
| ...                       |
+---------------------------+
| ...                       |
+---------------------------+
| ...                       |
+---------------------------+
| esp                       |
+---------------------------+   <-- 低地址 —— PCB
```

任务切换时，需要保存当前任务的上下文，以便下次切换回该任务时，能够恢复该任务的上下文。

```nasm
global task_switch
task_switch:
    push ebp
    mov ebp, esp

    push ebx
    push esi
    push edi

    mov eax, esp
    and eax, 0xfffff000 ; current

    mov [eax], esp

    mov eax, [ebp + 8]  ; next
    mov esp, [eax]

    pop edi
    pop esi
    pop ebx
    pop ebp

    ret
```

# 函数栈帧

- 栈帧布局：

    ```text
    +---------------------------+  <-- 高地址
    | ...                       |
    +---------------------------+
    | 参数 2                    |
    +---------------------------+
    | 参数 1                    |
    +---------------------------+
    | 返回地址                  |
    +===========================+  <-- ebp
    | 调用者的栈帧基址           |
    +---------------------------+
    | 局部变量 N                 |
    +---------------------------+
    | 局部变量 N - 1             |
    +---------------------------+
    | ...                       |
    +---------------------------+  <-- 低地址
    ```

- 栈帧切换：

```nasm
func:
    ; 等价于 enter
    push ebp
    mov ebp, esp
    ...
    ; 等价于 leave
    mov esp, ebp
    pop ebp
    ret
```

- 返回值通常放在 eax 寄存器中。

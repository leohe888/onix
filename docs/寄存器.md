# 寄存器

## 8086

- 通用寄存器（16位，其中 AX、BX、CX、DX 又可以拆分为两个独立的 8 位寄存器使用）：
  - AX：
    - AH
    - AL
  - BX：
    - BH
    - BL
  - CX：
    - CH
    - CL
  - DX：
    - DH
    - DL
  - SP
  - BP
  - SI
  - DI
- 段寄存器（16 位）：
  - CS
  - DS
  - SS
  - ES
- 指令指针寄存器（16 位）：IP
- 标志寄存器（16 位）：FLAGS
- 其他：
  - 全局描述符表寄存器（48 位）：GDTR
  - 中断描述符表寄存器（48 位）：IDTR

## x86

- 通用寄存器（32位，这些寄存器可以直接使用其低 16 位，即原来的 AX，BX，CX，DX，SP，BP，SI，DI，而 AX、BX、CX、DX 又可以拆分为两个独立的 8 位寄存器使用）：
  - EAX：
    - AX
      - AH
      - AL
  - EBX：
    - BX
      - BH
      - BL
  - ECX：
    - CX
      - CH
      - CL
  - EDX：
    - DX
      - DH
      - DL
  - ESI
    - SI
  - EDI
    - DI
  - ESP
    - SP
  - EBP
    - BP
- 段寄存器（16 位）：
  - CS
  - DS
  - SS
  - ES
  - FS
  - GS
- 指令指针寄存器（32 位）：EIP
- 标志寄存器（32 位）：EFLAGS
- 控制寄存器（32 位）：
  - CR0
  - CR1
  - CR2
  - CR3

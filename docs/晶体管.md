# 晶体管

晶体管（transistor）可分为：

- 二极管。
- 三极管，也可也称为双极型晶体管（Bipolar Junction Transistor，BJT），可用于放大和开关，有三个电极：发射极（Emitter，E）、基极（Base，B）和集电极（Collector，C）。
- MOSFET（Metal Oxide Semiconductor Field Effect Transistor，金属氧化物半导体场效应晶体管），有三个电极：源极（Source，S）、栅极（Gate，G）和漏极（Drain，D）。
- iGBT（insulated Gate Bipolar Transistor，绝缘栅双极型晶体管）。

# 蜂鸣器

蜂鸣器（也称为 PC Speaker）是 IBM PC 兼容机中最原始的音频设备，主要用于提供简单的听觉反馈。ASCII 码中的 `\a` 字符会触发蜂鸣器发出一声短暂的哔哔声。

蜂鸣器的控制依赖两个关键芯片：

- 可编程间隔定时器（Programmable Interval Timer，PIT）—— Intel 8253/8254 的通道 2，用于产生精确方波信号，控制蜂鸣器音调频率。
- 键盘控制器 Intel 8255/8042 的端口 0x61，用于控制蜂鸣器的开关状态。该端口是一个 8 位寄存器。其中，位 1 控制蜂鸣器的电源开关，位 0 控制 PIT 通道 2 到蜂鸣器的连接。必须同时将位 1 和位 0 都设置为 1。这样，PIT 通道 2 产生的方波才能到达扬声器。
